# 瞑想呼吸ラウンドタイマー

4-7-8呼吸法・ボックスブリージング・腹式呼吸の3パターンから選択し、拡縮アニメーションの円と音声ビープで呼吸フェーズを誘導するタイマーアプリです。セッション完了数がlocalStorageに記録されます。

## 機能
- 3種類の呼吸パターン選択（4-7-8呼吸法・ボックスブリージング・腹式呼吸）
- 吸入・保持・呼出フェーズに合わせた円のアニメーション（拡大・縮小）
- 現在のフェーズ名（吸ってください／保持／吐いてください）とカウントダウン表示
- AudioContextによるフェーズ切り替えビープ音
- ラウンド数の設定（3〜20回）
- セッション開始・停止ボタン
- 完了セッション数と最近の履歴をlocalStorageに保存・表示
